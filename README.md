# 骸骨深淵 · Abyss of Bones

暗黑破壞神風格的 3D 動作 RPG。中文 / English。

- **一層一層往下**：每一層都是隨機生成的洞窟（細胞自動機挖出來的岩壁、石板、骨堆、鐵火盆、青色水晶）。找到方尖碑、喚醒它，守在旁邊直到充能完成，骸骨會從四面八方的地底爬出來；每三層是骸骨之王的王座。
- **成群的亡者**：骷髏戰士（劍與盾）、骷髏斥候（快）、骷髏弓手、骷髏法師（藍色法球）、骨巨人（重擊會先在地上出現警告），還有金色的精英和骸骨之王（地面重擊、召喚骷髏）。幾百具骷髏一起動也不卡（所有骨頭都用 instancing 畫），打碎時骨頭四散。
- **技能**：揮劍（左鍵）、翻滾（空白鍵，無敵）、還有升級時學的技能：火焰柱、冰霜新星、連鎖閃電、旋風斬、祝福之錘、隕石術，每個最多 5 級；或選被動（力量、體魄、迅捷、疾行、精準、吸血、智慧、貪婪）。
- **裝備**：武器、頭盔、胸甲、手套、靴子、戒指、項鍊；普通、魔法（藍）、稀有（黃）、傳說（橘，會改變技能：雙生烈焰、天崩、永凍之環、風暴之心……）。地上的裝備有光柱和名字，背包裡 ▲ 表示比身上的好。
- **紙娃娃系統**：穿上的裝備會直接出現在角色身上：鐵盔、巨盔、骨冠、翼盔；鎖子甲、板甲、鱗甲、聖騎士胸甲；皮手套、鐵手甲、骨爪手套；皮靴、戰靴、板靴；長劍、闊劍、巨劍、戰斧、戰錘、鏈錘，還有項鍊和戒指。稀有度看得出來：普通是鐵、魔法是藍鋼、稀有鍍金、傳說是發光符文的黑鋼。沒穿的部位會露出底下的布衣、頭髮和鬍子。按 I 打開裝備畫面：中間是會轉的 3D 人物（可以拖曳轉動），周圍是七個裝備格，背包用圖示顯示。
- **營地**：每層結束後到營火：買藥水、賭神秘裝備、賣掉雜物、用靈魂在骸骨祭壇換永久符文。
- **畫面**：參考暗黑的俯視視角：暗綠色的洞窟、火光、泛光（bloom）、紅色生命球和藍色法力球、技能列、經驗條、右上小地圖、上方方尖碑進度條、左上的靈魂 / 擊殺 / 金幣。

**操作**：WASD 或滑鼠左鍵移動；點骷髏攻擊（Shift + 左鍵原地揮砍）；1–4 / 右鍵放技能；空白鍵翻滾；Q 藥水；I 背包；Tab 地圖；K 升級；Esc 暫停。手機：左邊搖桿、右邊按鈕。

Play: https://ywchen0711.github.io/abyss/
